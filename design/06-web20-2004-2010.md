# DESIGN.md: Web 2.0 (2004-2010)

## Purpose

Recreate the glossy, rounded, gradient-heavy style of the Web 2.0 era: bubbly icons, reflective buttons, pill shapes, bold sans-serif headlines, and soft shadows.

## Non-negotiable rules

- Every primary button must have a gradient fill and a visible top highlight.
- Every main card must have rounded corners between 8px and 12px.
- Every page must include a large hero heading in bold sans-serif.
- Use drop shadows on cards and buttons. Do not make elements flat.
- Icons must be glossy, bubbly, or 3D-looking.

## Colors (exact)

- Primary blue: `#3D8BFF`
- Dark blue: `#1E5AA8`
- Green accent: `#7AC943`
- Orange accent: `#FF8C1A`
- Light gray background: `#F5F7FA`
- Gradient top: `#FFFFFF`, gradient bottom: `#E8E8E8`
- Text: `#222222`
- Secondary text: `#666666`
- Shadow: `0 2px 6px rgba(0,0,0,0.2)`
- Highlight overlay: `linear-gradient(rgba(255,255,255,0.4), rgba(255,255,255,0))` over the top half of buttons

## Typography

- Font stack: `"Helvetica Neue", Helvetica, Arial, sans-serif`
- H1 (hero): 36px, bold, `#222222` or white on blue
- H2: 24px, bold
- H3: 18px, bold
- Body: 14px to 16px, line height 1.5
- Button text: 14px, bold, white with a subtle text shadow `0 -1px 0 rgba(0,0,0,0.3)`

## Layout

- Container: 1000px to 1100px wide, centered.
- Header: logo left, search box center or right, user menu right, height about 60px, gradient background.
- Hero section: large headline, one-line subtitle, a primary call-to-action pill button, and a screenshot or illustration.
- Feature grid: 3 cards in a row, each with a glossy icon, heading, and short text.
- Cards: white background, 10px border radius, 1px `#D9DEE5` border, soft shadow.

## Components

- Primary button: pill shape (`border-radius: 999px`), `#3D8BFF` gradient to `#1E5AA8`, white text, glossy highlight on top
- Secondary button: pill shape, white to `#E8E8E8` gradient, dark text
- Tags: small rounded rectangles in `#7AC943` or `#FF8C1A`
- Search box: rounded input with inner shadow and a glossy magnifier icon
- Navigation tabs: rounded tabs with a gradient active state
- Footer: dark blue gradient band with light gray links

## Imagery and effects

- Glossy 3D icons with highlights and reflections
- Reflection effect under logos or screenshots (lower 20% faded)
- Faint skeuomorphic textures allowed in headers (subtle brushed metal or wood, low opacity)
- Soft shadows on all raised elements
- Avoid heavy animation; subtle hover states only

## Forbidden

- Flat design with no gradients or shadows
- Sharp square corners on buttons and cards
- Dark-mode default
- Modern fonts such as Inter or SF Pro
- Neon or highly saturated color schemes outside the palette above
- Heavy animation or parallax

## Output rules for AI

- Output one HTML file with a single `<style>` block.
- Buttons must be pill-shaped with gradient and highlight.
- Use the exact colors and shadow values listed above.
- Include a hero section, a feature grid of three cards, and a gradient footer.
