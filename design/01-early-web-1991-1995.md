# DESIGN.md: Early Web (1991-1995)

## Purpose

Recreate the first generation of web pages: plain, text-first documents with no CSS, no images beyond small GIFs, and default browser styling.

## Non-negotiable rules

- No CSS files and no `<style>` blocks. Use only HTML elements and their browser defaults.
- No layout frameworks, flexbox, grid, or media queries.
- Use only the element set: `<h1>`-`<h6>`, `<p>`, `<a>`, `<ul>`, `<ol>`, `<li>`, `<hr>`, `<pre>`, `<address>`, `<br>`, `<img>` (small GIFs only), `<dl>`.
- Full page content must be readable at 640px wide.

## Colors (exact)

- Background: `#FFFFFF`
- Text: `#000000`
- Unvisited link: `#0000EE`
- Visited link: `#551A8B`
- Links are underlined by default. Do not remove underlines.

## Typography

- Font: `Times New Roman, Times, serif`
- Body size: 16px (browser default)
- Headings: browser default `<h1>` to `<h3>`. No custom sizes.
- Left-aligned text only. No centered layouts.

## Layout

- Single column, left aligned, default margins (8px body margin).
- Separate sections with `<hr>`.
- Navigation is a plain list of links at the top or bottom.

## Components

- Home page: `<h1>` title, short intro `<p>`, `<hr>`, a list of links to other pages.
- Under construction notice: small GIF plus the text "This page is under construction."
- Footer: `<address>` with a contact name and email link.

## Forbidden

- Any color beyond the exact colors above.
- Rounded corners, shadows, gradients, icons that are not GIF.
- Modern fonts (Arial, Helvetica, system UI fonts, Inter).
- Responsive design or any element that resizes with the viewport.

## Output rules for AI

- Output a single HTML file with no external CSS or JavaScript.
- Do not add comments or wrapper classes that imply CSS.
- If a feature would need CSS to build, leave it out and say so.
